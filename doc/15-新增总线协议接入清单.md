# 新增总线协议接入清单

以 YJ216（液晶载荷，family `yj216`）为样例。下次再加一套与 BIU / XL 并列的 CAN 总线，按本表逐项改，不要从 BIU 调用链反推。

约定：

- 路径族小写（`/yj216/`），存储键前缀大写（`YJ216:表号`）。
- 未知 family 不得落到 BIU。空 family 直接报错，三套总线协议地位相同。
- 新总线族先在 `module_payload/protocol_catalog.py` 的 `BUS_FAMILIES` 加一行（family、存储前缀、组装器 id/名/说明、解释器 id/名、遥控 JSON、遥测 JSON、gpcan 协议名、遥控封帧协议名）。不要再在 `list_assemblers`、`list_parsers`、`normalize_family`、`family_from_tm_path`、`get_telemetry_cfg`、`merge_telemetry_pages`、`cfg_id_for_family`、`_assembler_to_protocol` 里写族名。类注册仍在 `assemblers/__init__.py` 和 `parsers/__init__.py`。
- 组帧走该协议自己的 gpcan 包。遥测 SUM 写在自己的解析模块里。可以共用入队、配置加载和 TeleMetry 字段解析。
- 默认打开的组装器 / 解释器仍是 BIU。

## 功能 → 文件

| 功能 | 要改的文件 | YJ216 落点 |

## 不要做的事

- 不要复制遥控 Vue。
- 不要把新族的编号写成 `K*` 或 `JGB*`。文档有代号用文档代号，否则用族前缀按表序编。
- 不要在 JSON、页面或采集进程里再写一份目标地址字面量。
- 不要改 BIU 的默认打开组装器 / 解释器。
