# 新增总线协议接入清单

以 YJ216（液晶载荷，family `yj216`）为样例。下次再加一套与 BIU / XL 并列的 CAN 总线，按本表逐项改，不要从 BIU 调用链反推。

约定：

- 路径族小写（`/yj216/`），存储键前缀大写（`YJ216:表号`）。
- 未知 family 不得落到 BIU。空 family 直接报错，三套总线协议地位相同。
- 后端只写两处：协议清单一行，加一个协议包。框架文件不改。
  - 清单：`module_payload/protocol/protocol_catalog.py` 的 `CAN_BUS_FAMILIES` 加一行 `CanBusFamily(family='<族>')`。解释器显示名不是「`{族名大写}-CAN遥测复合帧`」时再传 `parser_name`。其余都由族名推出，不要另写：存储前缀与 gpcan 协议名 = 族名大写；组装器 id 与遥控封帧协议名 = `can_<族>`；解释器 id = `tm_can_<族>`；两份 JSON = `<族名大写>-TeleControlCfg.json` / `<族名大写>-TeleMetryCfg.json`；协议包 = `module_payload.protocol.<族>.can`。
  - 不要在 `protocol_catalog.py` 或 `constants.py` 加 `ASSEMBLER_CAN_<族>` / `PARSER_TM_CAN_<族>` 常量。要某族的 id 用 `bus_assembler_id(族)` / `bus_parser_id(族)`；要全部总线就遍历 `CAN_BUS_FAMILIES`。
  - 协议包：`module_payload/protocol/<族>/can/`，与现有三条总线文件相同：`tc.py`、`tm.py`、`tm_timed.py`、`__init__.py`。`__init__.py` 导出 `BINDINGS = ProtocolBindings(...)`（字段见 `protocol/hooks.py`）。没填的钩子走框架默认。
  - 入口函数用统一的名字，不带族名：`tc.py` 的 `assemble`，`tm.py` 的 `verify_tm`、`reset_tm_mgr`，`tm_timed.py` 的 `timed_tm`；需要时 `tc.py` 再加 `build_can_command`、`node_addr`。`tests/protocol/test_protocol_registry.py` 检查文件集合和函数名。
- 框架只经 `protocol/registry.py` 按清单查钩子。`can_collector`、`can_timers`、`fileplay/registry`、`payload_canplay_service`、`device_can`、`protocol/registry`、`protocol/can_feed`、`protocol/hooks` 里不写族名，`tests/protocol/test_protocol_registry.py` 会逐行扫。
- 各族协议包之间不互相 import，同一测试用 AST 检查。各族共用的只有组件编码 `cfg/telecontrol_assembler.py`（`encode_component`、`is_broadcast_hex`）、`constants.checksum_u8`、gpcan，以及 `module_payload/tm/` 的入队和配置缓存。
- 默认打开的组装器 / 解释器仍是 BIU，写在清单的 `DEFAULT_BUS_FAMILY`。
- 遥控 JSON 在配置缓存里只用 cfgId（如 `yj216-tc`），不登记旧缓存键。

## 功能 → 文件

| 功能 | 要改的文件 | YJ216 落点 |
| --- | --- | --- |
| 遥控 JSON | `ruoyi-fastapi-backend/assets/config/<族名大写>-TeleControlCfg.json`（文件名由族名推出，不能另起） | 第 7 章。短指令 4 字节原样。复帧指令自带固定长度：LCWP `00 09`，TEC / 功率 `00 06`，再加数据类型 `15` 和指令码。`check=是` 时 SUM 覆盖这些字节。发送时按 8 字节切 CAN 数据域，不再另加长度 |

| 协议清单 | `module_payload/protocol/protocol_catalog.py` 的 `CAN_BUS_FAMILIES` | 一行：`CanBusFamily(family='yj216', parser_name='YJ216-CAN实时遥测')`。推出 `YJ216` / `can_yj216` / `tm_can_yj216` / `YJ216-*Cfg.json` / gpcan `YJ216` / `module_payload.protocol.yj216.can` |

## 不要做的事

- 不要复制遥控 Vue。
- 不要在框架文件里按族名写分支。协议差异都放进本族的 `BINDINGS`。
- 不要从一个族的包 import 另一个族。规则相同也各写一份（BIU 与 XL 的总线遥控组帧就是两份）。
- 不要把新族的编号写成 `K*` 或 `JGB*`。文档有代号用文档代号，否则用族前缀按表序编。
- 不要在 JSON、页面或采集进程里再写一份目标地址字面量。
- 不要改 BIU 的默认打开组装器 / 解释器。
- 不要在清单行里手写 id、JSON 名、gpcan 名或模块路径。某个族真不跟族名走时，先给 `CanBusFamily` 加可选字段，再登记。
